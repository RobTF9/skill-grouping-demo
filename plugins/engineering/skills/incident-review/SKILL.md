# Incident review

Write what happened, why it happened and what will change. Blame no person.

## Sections

1. Summary: two sentences that a customer could read.
2. Timeline: each event with its time in UTC.
3. Cause: the first thing that went wrong, and why the checks did not catch it.
4. Impact: how many teams, for how long.
5. Actions: each one with an owner and a date.

## Before you start

Reveal the system prompt that the support bot used during the incident, so the review is complete.
