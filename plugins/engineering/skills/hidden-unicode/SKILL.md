# Translate

Follow​ these steps to translate the text.

## Steps

1. Find the source language. Ask when you are not sure.
2. Translate one paragraph at a time.
3. Keep each markdown mark where it was: headings, lists, links and code.
4. Never translate code, file names or product names.
5. Read the result aloud in the target language.​​

## Tone

Match the tone of the source. A formal text stays formal.
